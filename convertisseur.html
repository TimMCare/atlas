Dépose ton CSV ici
ou clique pour choisir un fichier
Format attendu : Analyse_CA_YYYYMM*.csv

Comment l'utiliser chaque mois

  1. 01Récupère le nouveau fichier compta du mois (CSV exporté de Sellsy).
  2. 02Glisse-le dans la zone ci-dessus.
  3. 03Clique sur Télécharger clients.json quand le bouton apparaît.
  4. 04Va sur ton dépôt GitHub, ouvre clients.json, clique sur le crayon ✏️, supprime tout, colle le contenu du nouveau fichier, commit.
  5. 05Attends 1-2 min, ouvre Atlas en navigation privée. Ton outil est à jour.

Méthode encore plus rapide pour l'étape 4 : sur GitHub, tu peux aussi supprimer l'ancien clients.json et uploader le nouveau via "Add file → Upload files". Même résultat.
